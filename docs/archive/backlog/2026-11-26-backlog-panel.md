# Подсистема 3: бэклог и планы на панели

Зачем: задачи, планы и решения всех проектов записаны файлами по стандарту, но на сайте их нет;
владелец хочет видеть их в Warehouse, а не ходить по репозиториям.

Готово, когда:
- на главной есть блок «Задачи ждут вас» и у проектов стадия и число задач;
- страница `/backlog` показывает задачи всех проектов с фильтрами, у проекта — паспорт, планы и решения;
- на боевом сервисе видны записи всех шести репозиториев;
- правка задачи в `main` репозитория появляется на странице без ручных действий.

Заметки: строка в [дорожной карте](../../roadmap.md). Не входит: правка задач с сайта, Telegram,
архив, замок на задачу.
