# Новый вид панели по макету

Зачем: владелец смотрит панель одинаково часто с телефона и с компьютера; старая страница была
одной колонкой списков, без сводки, без истории сборок и без быстрого перехода по проектам.

Готово, когда:
- на широком экране боковое меню с разделами и проектами, на телефоне панель вкладок;
- обзор: четыре показателя, «Ждёт вас» одним списком (просьбы, PR и CI, задачи владельца) с
  вкладками и подробностями по нажатию (справа на компьютере, снизу на телефоне), с действиями
  «отложить» и «закрыть»;
- график минут сборок macOS по проектам за 14 дней, с таблицей;
- страница «Проекты» карточками: этап, что ждёт, полоса задач по состояниям, сессии, PR, активность;
- браузерные тесты на телефоне и компьютере, светлая и тёмная тема, без горизонтальной прокрутки.

Заметки: макет одобрен владельцем 2026-11-26 (артефакт «Warehouse — макет панели»). Данные графика
— `lib/domain/mac-history.ts`, сборка обзора — `lib/domain/overview.ts`.
