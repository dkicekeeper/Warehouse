# Доставка вебхука записывается до применения

Зачем: если применение события упало, повтор GitHub считается дублем и событие теряется до следующей сверки.

Готово, когда:
- доставка помечается принятой после успешного применения, либо обе записи идут одной транзакцией;
- тест: упавшее применение не делает повтор дублем.

Заметки: Из итогового ревью диспетчерской (2026-11-26), отложено как некритичное.
