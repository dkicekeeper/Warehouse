# Сессии проектов не отчитываются в Warehouse

Зачем: на панели нет ни одной сессии Tenra, Dalada, Platina, DesignKit и Baja.kz: владелец не
видит, что они ждут его, хотя хук стоит во всех пяти репозиториях с 2026-11-26.

Готово, когда:
- найдена причина, почему отчёты сессий проектов не доходят (или не отправляются);
- после исправления новая сессия в каждом из пяти репозиториев видна на панели с проектом и
  строкой состояния;
- случай покрыт тестом или проверкой там, где он возникает.

Заметки: найдено первым аудитом гайдлайнов (`docs/archive/audit-2026-11-28.md`, SES-1, SES-2).
В базе за всё время три сессии: две Warehouse и одна проверочная без репозитория. Гипотезы:
сессии Tenra идут в окружении «Tenra», где нет сетевого секрета токена
(`2026-11-26-tenra-report-token.md`), и сервер отвечает 401; сессии других проектов начались до
мержа хука (хуки читаются при старте сессии); облачные сессии проектов идут в окружении без
скрипта настройки. Проверить по журналу запросов `/api/report/session` в Vercel и по `stop_hook_summary`
в журнале сессии проекта.
