# Сессии проектов не отчитываются в Warehouse

Зачем: на панели нет ни одной сессии Tenra, Dalada, Platina, DesignKit и Baja.kz: владелец не
видит, что они ждут его, хотя хук стоит во всех пяти репозиториях с 2026-11-26.

Готово, когда:
- найдена причина, почему отчёты сессий проектов не доходят (или не отправляются);
- после исправления новая сессия в каждом из пяти репозиториев видна на панели с проектом и
  строкой состояния;
- случай покрыт тестом или проверкой там, где он возникает.

Заметки: найдено первым аудитом гайдлайнов (`docs/archive/audit-2026-11-28.md`, SES-1, SES-2).

Причина (2026-11-28): облачная сессия всегда работает из `/home/user` — так в стартовом событии
сессии DesignKit от 2026-11-26 (`"cwd":"/home/user"`) и в журнале этой сессии; хук из
`.claude/settings.json` репозитория при этом не регистрируется, и отчёт не уходит. Хук в
репозиториях помогает только локальным сессиям, начатым в папке репозитория.

Исправление: хук ставится для пользователя скриптом настройки окружения (`hooks/README.md`,
«Уровень окружения»). В окружении Default он стоит с 2026-11-26; новая сессия там отчиталась
(проверено). Осталось окружение Tenra (`2026-11-26-tenra-report-token`): ограниченная сеть, нет
токена, нет скрипта. Сессии, чей контейнер собран раньше скрипта, отчитываются только после
перезапуска контейнера.
