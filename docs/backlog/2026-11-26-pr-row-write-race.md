# Гонка при записи строки PR

Зачем: два события одного PR, пришедшие одновременно, пишут строку целиком и могут затереть поля друг друга.

Готово, когда:
- запись PR меняет только поля своего события или идёт под блокировкой строки;
- тест с двумя одновременными событиями не теряет поля.

Заметки: Из итогового ревью диспетчерской (2026-11-26), отложено как некритичное.
