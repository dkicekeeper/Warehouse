# Гайдлайны: один свод правил для владельца и агентов

Зачем: правила работы разбросаны по CLAUDE.md шести репозиториев и расходятся; владелец их не
видит, агент не может проверить по ним проекты.

Готово, когда:
- общие правила записаны в `standard/guides/` с номерами, «почему» и способом проверки;
- раздел «Гайдлайны» на сайте показывает их, с кнопкой «Предложить правку»;
- блок в CLAUDE.md проектов собирается из гайдлайнов, тест сверяет номера;
- первый аудит шести репозиториев проведён, расхождения записаны задачами.
