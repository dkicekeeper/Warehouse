# Обновить копии хука отчёта в репозиториях проектов

В пяти репозиториях проектов лежит старая копия `.claude/hooks/warehouse-report.py`: без защиты от
двойной отправки. Когда окружение ставит хук и для пользователя, такая копия шлёт отчёт второй раз
(сервер принимает его как тот же статус, вреда нет, но лишний запрос). Обновить копии
PR с одним этим файлом: сборки macOS приложений на `.claude/` не запускаются (фильтры путей CI).

Аудит 2026-11-28: копии обновлены PR в Tenra, Dalada, Platina и Baja.kz. Осталась DesignKit: её
CI (`.github/scripts/ci_changes.py`) считает `.claude/` частью сборки и запустил бы задания macOS;
сначала добавить `.claude/` в `NO_BUILD_DIRS`, затем обновить копию.
