# Мелкие замечания ревью к панели бэклога

Зачем: ревью ветки панели бэклога (2026-11-26) нашло случаи, которые сейчас не мешают, но
стоят лишних запросов или могут удивить.

Готово, когда:
- репозиторий, на который приложение GitHub больше не установлено, не держит отметку «прочитать»;
- пуш, пришедший между чтением дерева и записью, не теряет отметку;
- ветка читается как `heads/<ветка>` (имя со слэшем или похожее на тег не путается);
- ссылка-симлинк в `docs/` не читается как документ;
- при неизменённом дереве строки не переписываются, а смена разбора перечитывает репозитории;
- `/api/board` считает сводку без текстов задач;
- успешное чтение отмеченных репозиториев снимает старую ошибку `docs_sync`;
- первый тик после выкладки не читает все репозитории одним вызовом функции (порция за тик).
