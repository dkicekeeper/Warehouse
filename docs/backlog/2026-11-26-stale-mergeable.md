# Устаревший mergeable у PR

Зачем: «готов к мержу» опирается на `mergeable`, который GitHub считает лениво: после пуша в `main` он устаревает.

Готово, когда:
- перед показом «готов к мержу» значение перечитывается или обновляется при пуше в базовую ветку.

Заметки: Из итогового ревью диспетчерской (2026-11-26), отложено как некритичное.
