# Мелкие замечания ревью к проверке стандарта

Зачем: итоговое ревью ветки стандарта (2026-11-26) нашло случаи, которых нет в настоящих
репозиториях, но которые могут дать ложное срабатывание или пропуск.

Готово, когда:
- ссылки: код в двойных обратных кавычках, блоки кода с отступом, HTML-комментарии, ограда из
  четырёх кавычек, скобки в адресе, `?query` не дают ложных `[link]`; ссылки-сноски проверяются;
- оглавление сверяется по точному пути, а не по подстроке;
- `pr` и `branch` проверяются по типу; повтор ключа в шапке — нарушение; списки YAML столбиком
  дают понятное сообщение;
- `standard` в паспорте не больше `standard/VERSION`; `ignore` на весь `docs` — нарушение;
- у задачи `ready` размера `l` проверяется наличие и статус плана;
- `sync_block.py`: метки внутри кода не считаются; файл с CRLF получает блок с CRLF; нет файла —
  сообщение, а не трассировка;
- `workflow.yml`: пуш блока повторяется после чужого пуша; проверка идёт и по расписанию;
- нарушения одного файла идут по порядку строк.
