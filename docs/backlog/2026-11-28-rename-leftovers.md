# Хвосты переименования репозитория и запроса «main красный»

Из ревью PR #14. Переименованный репозиторий переносится целиком, но остаётся мелкое:
хук отчёта в старых копиях сессий шлёт старое имя (`repo` в отчёте), и сессия попадает к имени,
которого уже нет; запрос последних прогонов `main` по каждому workflow (`distinct on` в
`loadSnapshot`) идёт без своего индекса и при росте таблицы `runs` станет медленнее.
