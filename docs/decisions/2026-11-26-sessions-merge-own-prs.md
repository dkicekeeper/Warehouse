# Сессия Warehouse мержит свои PR сама

Решение: сессия, которая ведёт работу Warehouse (сервис и стандарт, в том числе PR в репозиториях
проектов, которые эта работа открыла), мержит свои PR сама, как только CI зелёный, не спрашивая
владельца.

Почему: владелец, 2026-11-26: «мержи сам, не спрашивай меня». Ожидание мержа задерживало работу,
а проверку делает CI.
