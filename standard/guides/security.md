# Секреты

Как это устроено: все репозитории владельца публичные, вместе со всей историей и логами GitHub
Actions. Поэтому ключи живут только в секретах GitHub (для workflow), в настройках Vercel (для
сайтов) и в сетевых секретах облачного окружения Claude (их подставляет прокси в запросы к нужному
хосту, сессия значения не видит). В код попадают только ключи, сделанные, чтобы жить в приложении
(публичные ключи SDK).

### SEC-1. Репозитории публичные

Правило: всё, что попало в репозиторий, его историю или лог Actions, считается опубликованным.

Почему: решения владельца [«The repositories stay public»](https://github.com/dkicekeeper/Tenra/blob/main/docs/decisions/2026-11-10-repositories-public.md)
и [«Репозиторий Warehouse публичный»](https://github.com/dkicekeeper/Warehouse/blob/main/docs/decisions/2026-11-25-public-repository.md).

Проверка: аудит

Где: все

Агенту: да

### SEC-2. Секретов в репозитории нет

Правило: в репозитории только имена переменных (`.env.example`, примеры конфигов); значения — в
секретах GitHub, Vercel или окружения. Ключ, попавший в коммит, отзывают, а не только удаляют.

Почему: SEC-1; записано в `CLAUDE.md` Tenra, Dalada, Warehouse, Baja.kz.

Проверка: аудит

Где: все

Агенту: да

### SEC-3. Логи Actions ничего не выдают

Правило: workflow не печатает в лог токены, ответы сервисов с данными и личные данные.

Почему: логи публичные (SEC-1); записано в `CLAUDE.md` Warehouse для `tick.yml`.

Проверка: аудит

Где: все

Агенту: да

### SEC-4. Ключ для сессии — сетевой секрет окружения

Правило: ключ API, нужный облачной сессии, добавляют сетевым секретом окружения для его хоста; не
в переменную окружения, не в файл и не в чат.

Почему: прокси подставляет значение в запрос, сессия и логи его не видят (`hooks/README.md`
Warehouse: токен отчёта сессии).

Проверка: аудит

Где: все

Агенту: да

### SEC-5. Личные данные людей не попадают в репозиторий

Правило: выписки, имена, номера счетов и другие данные людей, которые сессия видит в работе, не
попадают ни в код, ни в тесты, ни в сообщения коммитов; фикстуры придумывают.

Почему: записано в `CLAUDE.md` Tenra (банковские выписки).

Проверка: аудит

Где: Tenra

Агенту: нет

## Коротко для агента

- Репозиторий публичный вместе с историей и логами Actions: что туда попало, опубликовано (SEC-1).
- Секретов в репозитории нет: только имена переменных; попавший в коммит ключ отзывают (SEC-2).
- Workflow не печатает в лог токены, ответы сервисов и личные данные (SEC-3).
- Ключ API для облачной сессии — сетевой секрет окружения, не переменная и не чат (SEC-4).
